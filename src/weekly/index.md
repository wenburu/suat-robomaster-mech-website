# 每周任务卡

<box type="info" seamless>
<b>每周任务卡</b>是机械组的每周节奏指挥棒，组长每周一发布，全员按卡执行。
<br>完整任务卡存档在飞书知识库「07_任务交付区/每周任务卡归档」。
</box>

## 规则

1. **必做项**：全员必须完成，提交到多维表格「进度跟踪表」。
2. **选做项**：有余力的成员完成，计入「弹性加分」。
3. **弹性机制**：考试周自动减量（只保留必做项的一半），无电脑成员做"图纸阅读"替代任务。
4. **截止**：每周日 23:59。

## 给组长的操作说明

1. 打开 [任务卡模板](template.md)，复制全文。
2. 在 `src/weekly/` 下新建 `week-N.md`，填入当周内容。
3. 在本文档的"已发布任务卡"表格加一行。
4. 同步发布到飞书「07_任务交付区/每周任务卡归档」。
