# F 阶段 · SolidWorks 基础草图

<box type="warning" seamless>
<b>阶段目标</b>：全员完成 SolidWorks 2026 安装激活，熟悉界面，能独立绘制规范草图。
<br><b>预计周期</b>：2-3 周（含弹性缓冲）
<br><b>适用对象</b>：机械组全员（12 人）
<br><b>软件版本</b>：SolidWorks <b>2026</b> 学生版 / RM 教育许可，全组统一
</box>

---

## 一、阶段总结

F 阶段是零基础起点。不追求做零件，只追求<b>把草图画对、画规范</b>。
草图是所有建模的根基，草图错了后面全错。

学完 F 阶段你应该能：

- [ ] 正确安装并激活 SolidWorks 2026 学生版 / RM 教育许可
- [ ] 说出特征树、属性管理器、图形区、命令管理器的位置
- [ ] 独立完成一个封闭草图，包含足够的几何约束和尺寸
- [ ] 知道"完全定义""欠定义""过定义"的区别
- [ ] 按规范命名文件并提交作业

<box type="info">
<b>特殊情况说明（基于问卷）</b>：
- 5 人未装 SW → 第 1 周集中解决安装，由已装成员一对一远程指导。
- 1 人无电脑（11 月中旬购）→ 本期以"图纸阅读 + 视频学习 + 结对笔记"替代，电脑到位后补实操。
- 3 人不确定配置 → 先装 SW 试用，跑不动反馈组长，用机房电脑。
</box>

## 二、学习项目（由易到难）

### F1 · SolidWorks 2026 安装与界面熟悉 ★

**时长**：2 小时
**目标**：装好软件，认识四个核心区域。

**步骤**：

1. **下载安装**
   - 路径：通过学校/运营组统一获取 SolidWorks 2026 学生版或 RM 教育许可安装包。
   - <box type="danger"><b>严禁使用破解版</b>。破解版会导致版本不一致、文件兼容问题，且有法律风险。全组统一版本号 2026。</box>
   - **安装求助**：装不上先在群里喊，已装好的 7 人每人结对带 1 个未装的同学远程指导。
2. **首次启动**
   - 选择"零件"模板进入。
3. **认识界面**（对着软件指一遍）：
   - **特征树（左）**：记录建模历史，删特征从这里删。
   - **属性管理器（左弹出）**：设置当前命令的参数。
   - **图形区（中间）**：建模的地方。
   - **命令管理器（顶部）**：草图/特征/装配体等标签页。
4. **练习**：随便画一个矩形，观察特征树出现了什么。

**产出**：截图你的 SolidWorks 主界面，圈出四个核心区域，发到群里。

<modal title="无电脑/未装SW替代方案（点击展开）">
- <b>无电脑成员（11月中旬购机）</b>：
  1. 看本页"四、外部链接"里的 B 站界面介绍视频，用手机/平板看 2 遍。
  2. 找结对成员要一张"界面四区标注截图"，自己复述每个区的用途（语音发给组长）。
  3. 在纸上画出你认为的界面布局草图，拍照提交。
  4. 电脑到位后，第一步就是装 SW + 补 F1 截图。
- <b>未装 SW / 配置不确定</b>：
  1. 先装 SW（参考上方步骤 1），装完跑一个矩形草图试试流畅度。
  2. 跑不动 → 反馈组长，安排机房电脑补练，本周任务改为"看视频 + 截图笔记"。
</modal>

<modal title="常见错误（点击展开）">
- **错误1**：装错版本（装成 2024/2025，其他人 2026）→ 文件打不开。**做法**：全组统一 2026，由组长确认。
- **错误2**：打开软件卡在"正在准备" → 重启电脑，或用管理员身份运行。
- **错误3**：把破解激活工具拷进群 → 立即撤回，违者组内通报。
</modal>

### F2 · 草图绘制基础 ★

**时长**：3 小时
**目标**：掌握直线、矩形、圆、圆弧、修剪、延伸。

**步骤**：

1. 新建零件 → 选前视基准面 → 进入草图。
2. 学 6 个核心命令：
   - 直线（L）
   - 矩形（R）：边角矩形 / 中心矩形
   - 圆（C）：中心圆 / 周边圆
   - 圆弧：三点圆弧 / 圆心/起/终点圆弧
   - 修剪（T）
   - 延伸（U）
3. **练习 1**：画一个 100mm × 60mm 的矩形，四个角倒 R10 的圆角。
4. **练习 2**：在矩形中心画一个 Φ20 的圆。

**产出**：两张草图截图（含尺寸标注），提交到多维表格。

<modal title="无电脑/弹性替代（点击展开）">
- 无电脑成员：看 B 站草图基础视频，边看边在纸上画"步骤流程图"（新建草图 → 画矩形 → 标注），提交手写笔记照片。
- 时间不足：只做练习 1，练习 2 选做。
</modal>

<modal title="常见错误">
- **错误1**：画线条时不看右下角提示栏（"水平""竖直"）→ 养成看提示的习惯。
- **错误2**：用"智能尺寸"硬拉尺寸，不先加几何约束 → 草图一拖动就变形。
- **错误3**：草图没封闭就退出 → SW 会报错"轮廓不闭合"，检查是否有出头线。
</modal>

### F3 · 草图约束与尺寸标注 ★★

**时长**：4 小时
**目标**：理解"完全定义"，草图变黑（不是蓝色）。

**核心概念**：

- **欠定义**：线条蓝色，还能动。
- **完全定义**：线条黑色，拖动不动。✅ 目标状态
- **过定义**：报错冲突，多余约束。

**几何约束类型**：
水平、竖直、重合、平行、垂直、相切、相等、对称。

**步骤**：

1. 画一个 L 形板：外轮廓 100×80，内凹 40×40。
2. 先加几何约束（水平/竖直/对称），再加尺寸。
3. 直到所有线条变黑。
4. 尝试拖动任意一条线，验证草图不会变形。

**产出**：L 形板草图（完全定义），提交。

<modal title="无电脑/弹性替代（点击展开）">
- 无电脑成员：用手机看"完全定义"讲解视频，整理"欠定义/完全定义/过定义"对照笔记（文字），提交。
- 考试周：本任务允许拆成两周完成，第 1 周只做"画 + 约束"，第 2 周补"尺寸 + 变黑验证"。
</modal>

<modal title="常见错误">
- **错误1**：尺寸标得越多越好 → 错。约束优先，尺寸只标关键尺寸。
- **错误2**：草图变黑就以为完了 → 要拖动验证，有时是"假完全定义"。
- **错误3**：过定义报错不会删 → 看特征树下方"显示/删除几何关系"，删掉冲突约束。
</modal>

### F4 · 简单拉伸零件练习 ★★

**时长**：4 小时
**目标**：从草图到第一个三维零件。

**练习项目**：一块连接板

要求：
1. 板尺寸：120mm × 80mm × 5mm
2. 四个角各一个 Φ6.6 的通孔（对应 M6 螺丝）
3. 中心一个 Φ20 的通孔
4. 倒 R2 圆角

**步骤**：
1. 前视基准面画草图（用 F3 的方法完全定义）。
2. 退出草图 → 特征 → 拉伸凸台 → 深度 5mm。
3. 选上表面 → 新建草图 → 画四个 Φ6.6 圆和中心 Φ20 圆。
4. 拉伸切除 → 完全贯穿。
5. 倒圆角。

**产出**：`F4_姓名_日期.SLDPRT` + 等轴测截图。

<modal title="无电脑/弹性替代（点击展开）">
- 无电脑成员：本任务是实操核心，电脑到位前暂缓；先提交"拉伸/切除概念笔记"，到位后 2 天内补交 SLDPRT。
- 配置不足：机房电脑补练，或借用结对成员的电脑远程演示一次。
</modal>

<modal title="常见错误">
- **错误1**：直接在实体面上画草图不选基准面 → 容易选错面。**做法**：新手先从前视/上视/右视基准面开始。
- **错误2**：拉伸方向反了 → 看预览箭头，不对就点"反向"。
- **错误3**：打孔不做"拉伸切除"而是硬画个凸台 → 孔就是切除，不是凸台。
</modal>

### F5 · F 阶段考核任务 ★★

**时长**：现场 90 分钟
**形式**：组会现场抽签，限时完成。

**题目（示例）**：
> 在 90 分钟内，根据给定二维图纸（组长现场发），完成一个零件的建模。要求：
> 1. 草图完全定义
> 2. 尺寸与图纸一致
> 3. 文件命名 `F考核_姓名.SLDPRT`

**评分**：
- 草图规范性（30%）
- 尺寸准确率（40%）
- 完成度（20%）
- 文件命名与提交（10%）

**通过线**：60 分。不通过者一周后补考。

<box type="info">
<b>无电脑成员考核说明</b>：电脑到位后可单独安排补考；若 11 月中旬仍未到位，先以"理论问答 + 纸上草图"形式考核，实操后补。
</box>

## 三、穿插任务

- **组会**：每周一次，每次 1 小时。前 30 分钟讲本周知识点，后 30 分钟答疑。
- **每日打卡**：在群里发当天练习截图，不用写感想。无电脑成员发"学习笔记"。
- **结对**：两人一组，互相检查对方草图是否完全定义。**安排 1 名已装 SW 成员结对 1 名未装/无电脑成员**。
- **每周任务卡**：组长每周一发布（见[每周任务卡](../weekly/index.md)），考试周自动减量。

## 七、常见错误合集

1. **版本不统一** → 全组锁定 SolidWorks **2026**，由组长确认后写入本页顶部。
2. **破解版** → 严禁。使用学校/官方教育许可。
3. **草图欠定义就拉伸** → 先变黑再退出草图。
4. **特征树乱** → 每个特征改名字（右键特征 → 重命名），例："拉伸-板厚5mm"。
5. **文件乱存** → 按规范命名，按任务编号归档。
6. **3D打印文件自己发群** → .STL 统一交加工负责人，机械组不负责打印执行。
7. **无电脑成员掉队** → 结对成员每周确认一次进度，组长在组会过一遍。
