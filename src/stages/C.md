# C 阶段 · 子系统设计深化

<box type="warning" seamless>
<b>阶段目标</b>：把 D 阶段的 v0.1 子系统迭代到 v1.0，引入公差、标准件、可维护性，输出可加工的工程图和 BOM。
<br><b>预计周期</b>：3-4 周
<br><b>前置</b>：D 阶段方向答辩通过
</box>

---

## 一、阶段总结

D 阶段你做出了"能看"的模型。C 阶段要做出"<b>能加工、能装、能修</b>"的模型。

核心转变：

1. **从"画出来"到"做出来"**：每个尺寸都要考虑加工工艺（3D 打印 / 激光切割 / CNC）。
2. **标准件优先**：螺丝、轴承、联轴器、铝型材，全部调用标准件，不要自己画。
3. **公差意识**：配合面给公差，非配合面给自由公差。
4. **可维护性**：电池快拆、电机快换、走线有槽。

---

## 二、学习项目

### C1 · 标准件库调用 ★★★★

**内容**：
- SW 工具箱（Toolbox）调用：内六角螺丝、螺母、垫圈、轴承。
- 学会配置 Toolbox 标准库（GB 国标）。
- 每个螺丝孔自动生成螺纹装饰线。

**产出**：在 D 阶段的底盘上，把所有紧固件换成 Toolbox 标准件。

<modal title="常见错误">
- 自己画螺丝 → 错。用 Toolbox，BOM 自动统计。
- Toolbox 没装 → 安装 SW 时勾选，或找组长要配置好的库。
</modal>

---

### C2 · 公差与配合 ★★★★

**内容**：
- 基孔制 / 基轴制。
- 间隙配合 / 过渡配合 / 过盈配合的应用场景。
- 3D 打印件的公差要放大（层纹影响）。

**练习**：
- 给 D1 的轴承孔标 H7，轴标 k6。
- 给 3D 打印件的孔留 0.2-0.3mm 间隙。

**产出**：一张带公差标注的零件图。

---

### C3 · 子系统 v1.0 迭代 ★★★★

**内容**：
- 根据 D 阶段答辩反馈，迭代自己方向的子系统。
- 加入：快拆结构、走线孔、减重孔、加强筋。
- 出工程图（交给工程图方向或自己出）。

**产出**：`D方向_v1.0.SLDASM` + 工程图 PDF。

---

### C4 · BOM 与加工对接 ★★★★

**内容**：
- 从装配体导出完整 BOM（含标准件数量）。
- 区分：3D 打印件 / 激光切割件 / CNC 件 / 标准件采购。
- <box type="info">机械组只出 BOM 和加工文件，<b>采购和打印由运营组/学校负责</b>。机械组指定 1 名采购沟通接口人对接。</box>

**产出**：BOM Excel + 加工文件包（.STEP / .STL / .PDF 工程图）。

---

## 三、C 阶段考核

- 子系统 v1.0 工程图完整，可直接交给加工方。
- BOM 准确，标准件数量无误。
- 设计说明里能讲清每个公差为什么这么给。

---

## 四、常见错误

1. **不调用标准件** → 螺丝螺母全自己画，BOM 一团乱。
2. **公差照搬教科书** → 3D 打印件公差和机加件不一样，要放大。
3. **BOM 漏件** → 导出后人工核对一遍。
4. **设计不考虑维护** → 螺丝全被挡住，后期拆不下来。
