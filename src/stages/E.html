E 阶段 · 零件建模与简单装配

阶段目标：掌握特征树逻辑，能做出带回转体/扫描特征的零件，并完成 3-5 个零件的简单装配体。
预计周期：2-3 周
适用对象：机械组全员（F 阶段通过后进入）
前置：F 阶段考核 ≥ 60 分

一、阶段总结

F 阶段你学会了"画草图 → 拉伸一块料"。E 阶段要学会：

  1. 特征是堆叠出来的：先做什么后做什么，决定了零件能不能改。
  2. 基准是定位的根：基准面、基准轴、原点，是所有对称设计的锚点。
  3. 复杂形状来自三个命令：旋转（轴类）、扫描（等截面长条）、放样（变截面）。
  4. 零件不是孤岛：要会把多个零件装起来，看干涉、出材料明细表。

学完 E 阶段，你应该能独立做出一个带手柄的简单机构（例如一个摇臂组件），并生成爆炸图。

二、学习项目（由易到难）

E1 · 特征树与基准 ★★

时长：3 小时 目标：理解"建模历史"，学会建基准面。

核心概念：

  • 特征树从上到下 = 建模顺序。
  • 特征可以拖动重排（但不是随便拖）。
  • 右键特征 → 编辑特征 / 编辑草图 / 删除。
  • 基准面：前视 / 上视 / 右视是默认三个；可以新建基准面（参考一条边 + 一个面）。

练习：

  1. 打开 F4 的连接板零件。
  2. 在特征树里把"拉伸切除"拖到"拉伸凸台"前面，观察会发生什么（理解顺序）。
  3. 新建一个基准面，平行于前视基准面，偏移 50mm。
  4. 在新基准面上画一个圆，拉伸凸台 10mm。

产出：截图特征树，能看到你新建的基准面。

E2 · 旋转特征（做轴类零件）★★

时长：3 小时 目标：用旋转做一个阶梯轴。

步骤：

  1. 前视基准面画草图：一条中心线（旋转轴）+ 一半的轴轮廓。
  2. 关键：必须画一条中心线作为旋转轴，草图在中心线一侧封闭。
  3. 退出草图 → 特征 → 旋转凸台/基体 → 360°。
  4. 做出阶梯轴：Φ20 长 30 + Φ15 长 20 + M6 螺纹孔。

产出：E2_阶梯轴_姓名.SLDPRT。

E3 · 扫描与放样 ★★★

时长：4 小时 目标：做出等截面长条（扫描）和变截面（放样）。

扫描（Sweep）：

  • 一条路径（草图/曲线）+ 一个轮廓（草图在路径端点的基准面上）。
  • 练习：做一个 L 形弯管，方截面 10×10，路径是 L 形折线。

放样（Loft）：

  • 两个或多个不同截面草图，放在不同基准面上，SW 自动过渡。
  • 练习：做一个圆变方的过渡接头：一端 Φ20 圆，一端 15×15 方，长度 30。

产出：两个零件 SLDPRT。

E4 · 简单装配体 ★★★

时长：5 小时 目标：把 3-5 个零件装起来。

步骤：

  1. 新建装配体（.SLDASM）。
  2. 第一个零件：插入后直接点"固定"（默认第一个零件自动固定）。
  3. 后续零件：用配合关系约束：
    • 重合：两个面贴在一起。
    • 同轴心：两个圆柱面/孔共轴。
    • 距离 / 角度：控制间距和角度。
  4. 装配一个简单组件：底板 + 阶梯轴（E2 做的）+ 两个支撑板。

关键原则：

  • 每个零件只需要足够约束让它"动不了该动的，能动能动的"。不要把自由度全锁死，否则改不动。

产出：E4_底板组件_姓名.SLDASM。

E5 · 爆炸视图与材料明细表 ★★★

时长：3 小时 目标：从装配体出爆炸图和 BOM。

步骤：

  1. 打开 E4 的装配体。
  2. 配置管理器 → 新建爆炸视图 → 拖动零件到分离位置。
  3. 回到装配体 → 插入 → 表格 → 材料明细表（BOM）。
  4. 导出 BOM 为 Excel（后续 C 阶段采购对接用）。

产出：爆炸视图截图 + BOM 表格。

E6 · E 阶段考核任务 ★★★

时长：现场 120 分钟 题目（示例）：

根据组长现场发的图纸，完成一个"摇臂组件"的建模与装配：

  1. 摇臂零件（带旋转特征 + 一个孔）
  2. 转轴零件（阶梯轴）
  3. 底座零件（一块板带两个孔）
  4. 三个零件装配，配合正确，无干涉
  5. 出爆炸视图截图

评分：

  • 零件建模正确性（30%）
  • 配合合理性（30%）
  • 无干涉（20%）
  • 爆炸视图与 BOM（20%）

通过线：60 分。

七、常见错误合集

  1. 特征顺序乱 → 建模前先想顺序：先料 → 加减材料 → 细节。
  2. 第一个零件没固定 → 装配体第一个零件必须固定。
  3. 配合过定义 → 保留必要配合，多余的删。
  4. 零件名是"零件1.SLDPRT" → 另存为时就改好名字。
  5. 换电脑丢零件 → 永远用"打包"提交装配体。
