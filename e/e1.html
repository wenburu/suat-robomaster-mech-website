E1 · 特征树与基准

建模历史 = 你的设计笔记

一、学习目标

  • 理解特征树：从上到下就是建模顺序，改模型就是改特征树
  • 学会编辑特征 / 编辑草图 / 特征重命名
  • 会新建基准面（偏移法），为 E2/E3 打基础

二、讲义：特征树就是"建模历史"

特征树（设计树）在界面左侧，记录了从第一个特征到最后一个特征的全部步骤。它就像菜谱：步骤顺序不同，结果不同。

操作怎么做什么时候用
编辑特征右键特征 → 编辑特征改拉伸深度、改圆角半径
编辑草图右键特征 → 编辑草图改形状、改尺寸
重命名左键慢点两下名字，或 F2每个特征都要改："拉伸-板厚5"
删除右键 → 删除（或按 Delete）做错了整步删掉重来
拖动重排按住特征拖到新位置极少用，且可能报错——新手别乱拖
先理解再改拖动特征重排会改变建模历史，很多新手在这里把模型改崩。E 阶段统一规则：不拖动重排，想改就编辑/删除重做。

三、讲义：三个默认基准面 + 新建基准面

SolidWorks 默认有前视、上视、右视三个基准面，是所有零件的地基。但很多零件需要在"空中"建特征，这时要新建基准面。

3.1 新建基准面（偏移法，最稳）

  1. 「特征」标签 → 「参考几何体」→ 「基准面」
  2. 选一个已有平面（如"前视基准面"）
  3. 属性管理器输入偏移距离（如 50mm），可改方向
  4. 点 ✅ 确定——特征树出现"基准面1"

3.2 基准面的作用

  • 在偏移出的基准面上画草图 → 生成"悬空"的特征
  • E3 扫描的轮廓草图、E2 旋转的草图，都常需要基准面配合
  • 隐藏/显示基准面：视图 → 隐藏/显示 → 基准面

四、练习项目

  1. 打开 F4 的连接板零件
  2. 观察：把特征树从上到下读一遍，说出每个特征是什么、为什么这个顺序
  3. 改名：把所有特征改成有意义的名字（拉伸-板厚5 / 切除-M6孔×4 / 切除-中心孔 / 圆角-R2）
  4. 改尺寸：编辑"拉伸-板厚5"，把深度改成 8mm，观察模型变化
  5. 新建基准面：平行于前视基准面，偏移 50mm，确认特征树出现"基准面1"
  6. 删掉它：右键"基准面1"删除，练习删除操作（没事，练习而已）

产出：特征树截图（含改名后的特征 + 新建的基准面）。

弹性方案：无电脑成员

画一张"特征树示意图"：左边画特征树（拉伸→切除→圆角），右边标注每个特征的含义；再抄写"新建基准面四步"。拍照提交。电脑到位后补实操。

六、提交要求

  • 命名：E1_姓名_日期（截图即可）
  • 提交到多维表格「进度跟踪表」

七、常见错误

  1. 特征拖乱导致报错 → Ctrl+Z 撤回，不要硬删。
  2. 基准面新建时选不到平面 → 先在特征树点一下目标基准面/面，再点"参考几何体→基准面"。
  3. 默认基准面被隐藏找不回 → 视图 → 隐藏/显示 → 基准面。
  4. 特征全是"拉伸1""切除1" → 不改名，别人看你的文件像看天书，必须改名。
