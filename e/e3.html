E3 · 扫描与放样

E3 扫描与放样：等截面靠扫描，变截面靠放样

这一部分讲什么

机器人上的弯管、线槽、把手、过渡接头，靠拉伸和旋转都做不出来。它们用的是另外两个命令：扫描（截面不变、沿路径走）和放样（两个不同截面之间平滑过渡）。这一部分把这两个命令学会。

扫描（Sweep）

扫描 = 一个轮廓沿着一条路径移动。想象一根吸管沿弯曲线条穿过：吸管截面不变，只跟着路径拐弯。

扫描两大要素

  • 路径：一条草图/曲线/边线（控制走向）
  • 轮廓：一个封闭草图（控制截面形状）
扫描第一铁律轮廓草图必须画在路径端点的基准面上。做法：先在路径端点处新建基准面（E1 的技能），再在该基准面上画轮廓。

扫描步骤（弯管实例）

  1. 前视基准面画路径：L 形折线（两条线，拐角处倒 R10 圆角）→ 退出草图
  2. 在折线端点新建基准面（选端点 + 垂直于曲线）
  3. 在该基准面上画轮廓：10×10 方形，中心对准路径端点 → 退出草图
  4. 「特征」→ 「扫描凸台/基体」
  5. 轮廓选方形草图，路径选 L 形草图 → 确定

放样（Loft）

放样 = 在两个或多个不同截面之间平滑过渡。典型例子：圆管接口变方管接口。

放样步骤（圆变方实例）

  1. 前视基准面 → 草图 → 画 Φ20 圆 → 退出草图
  2. 新建基准面，偏移前视 30mm → 在该基准面画 15×15 方（中心对齐）→ 退出草图
  3. 「特征」→ 「放样凸台/基体」
  4. 依次选两个截面草图（注意选择顺序和起点方向）→ 确定
放样常见坑模型"扭了"，是因为两个截面的起点没对齐。点绿色连接点拖动，让起点对应起点，就不扭了。

常见问题

  1. 轮廓没画在路径端点：扫描报错或形状错乱，最高频错误。
  2. 放样扭了：拖动连接点对齐起点。
  3. 路径有尖角：尖角处扫描会自相交报错，先给路径拐角倒圆角。
  4. 扫描选错"轮廓/路径"：属性管理器里轮廓选截面草图、路径选走向草图，别反。
