E5 · 爆炸视图与 BOM

让装配体"拆开说话"，给采购一张账单

一、学习目标

  • 生成爆炸视图：把装配体零件拆开展示
  • 导出材料明细表（BOM）：每个零件的名称/数量/材料
  • 理解 BOM 是"对接采购的第一张账单"

二、讲义：爆炸视图

爆炸视图 = 把装配体里套在一起的零件"拉开"，让所有人一眼看懂结构。用途：组会讲解、装配指导、文档插图。

  1. 打开 E4 的装配体
  2. 点左下角「配置管理器」标签
  3. 右键配置名（默认"默认"）→ 「新建爆炸视图」
  4. 选要拆的零件 → 出现拖动箭头 → 沿箭头方向拖到合适位置
  5. 一个零件一步；全部拆完点 ✅ 完成
  6. 别忘了点"完成"，否则爆炸状态不保存
爆炸视图存在哪？爆炸视图存在配置里（配置管理器），不是模型空间。想恢复原样：配置里双击"默认"配置。

三、讲义：材料明细表（BOM）

BOM = Bill of Materials = 材料账单。它告诉采购和生产：这个组件有哪些零件、各多少个、什么材料。

3.1 生成 BOM 前置条件：零件必须有名字

  1. 打开每个零件 → 右键特征树顶部零件名 → 「属性」
  2. 在"自定义"标签里填：零件号（如 PLA-T-01）、材料（如 6061 铝）、说明（底板）
  3. 保存
BOM 里出现"零件1"= 不合格不填属性就导出 BOM，采购看到一堆"零件1"根本没法下单。E5 的验收标准之一就是 BOM 里没有无名零件。

3.2 导出 BOM

  1. 回到装配体 → 「插入」→ 「表格」→ 「材料明细表」
  2. 选择表格模板（默认即可）→ 放在图形区
  3. 右键表格 → 「另存为」→ 选 Excel 格式（.xlsx）

四、练习项目

  1. 给 E4 组件全部零件填好属性（零件号/材料/说明）
  2. 生成爆炸视图（至少 3 个爆炸步骤）
  3. 插入材料明细表并导出 Excel
  4. 检查 BOM：每个零件都有名字、数量正确

产出：爆炸视图截图 + BOM Excel，一起打包提交。

六、提交要求

  • 命名：E5_姓名_日期.zip（爆炸截图 + BOM Excel + 打包装配体）
  • 提交到多维表格「进度跟踪表」

七、常见错误

  1. 爆炸完没点"完成" → 白做，切换配置就没了。
  2. BOM 里全是"零件1" → 回去给每个零件填属性。
  3. BOM 数量不对 → 检查装配体里是不是漏装了零件。
  4. 只交 .SLDASM → 必须打包，否则零件缺失。
