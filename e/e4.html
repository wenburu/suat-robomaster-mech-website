E4 · 简单装配体

把零件装起来，不散架、不干涉

一、学习目标

  • 理解装配体（.SLDASM）与零件（.SLDPRT）的关系
  • 掌握三大配合：重合、同轴心、距离
  • 会做干涉检查，知道"配合过定义"怎么解决
  • 会用「打包」提交完整装配

二、讲义：装配的核心概念

装配体 = 把零件按位置"约束"在一起的文件。它不复制零件，只引用零件——所以零件文件不能丢，交作业必须「打包」。

2.1 配合（Mate）三件套

配合作用什么时候用
重合两个面贴在一起板与板、面与面定位
同轴心两个圆柱面/孔共轴轴穿进孔、螺丝穿进孔
距离两平面相距固定值留间隙、定间距
选面口诀配合前先想"哪两个面发生关系"——选面比选线稳；圆柱面选"面"而不是"边线"。

三、讲义：装配五步

  1. 新建装配体：文件 → 新建 → 装配体（.SLDASM）
  2. 插入第一个零件：第一个零件最好选"底座"，插入后固定（特征树里名字旁有个 (f)）
  3. 插入后续零件：插入 → 现有零件/装配体 → 选零件 → 在图形区放下
  4. 加配合：「装配体」标签 → 「配合」→ 依次选两个面 → 选配合类型 → ✅
  5. 检查：拖动零件看是否"动不了该动的、能动能动的"

四、讲义：干涉检查（必做！）

  1. 「评估」标签 → 「干涉检查」
  2. 点「计算」
  3. 有干涉：红色高亮区域 → 分析是配合错还是尺寸错 → 修改
干涉 = 真实世界的"撞车"图纸上干涉，加工出来就装不上或者干磨。RM 整车几十个零件，全靠装配后干涉检查兜底。E4 起每个装配体必须过干涉检查。

五、练习项目

项目名称：底板组件（底板 + 阶梯轴 + 两个支撑板）

  1. 底板：F4 连接板改一个（120×80×5，中心 Φ20 孔）
  2. 支撑板 ×2：60×40×5，中心 Φ8 孔（竖着装）
  3. 阶梯轴：用 E2 的（Φ15 段要能穿进 Φ20 孔，做个 Φ15 段）
  4. 装配：底板固定 → 支撑板与底板"重合+距离"定位 → 阶梯轴与孔"同轴心"
  5. 干涉检查：必须 0 干涉
  6. 保存 → 文件 → 打包 → 生成 zip

产出：E4_底板组件_姓名.zip（内含装配体+全部零件）+ 无干涉截图。

弹性方案：无电脑成员

用纸笔画"装配关系图"：底板在上、支撑板在下、轴穿中心孔，标出每对配合（底板-支撑板：重合+距离；轴-孔：同轴心）。拍照提交。电脑到位后按图装配。

七、提交要求

  • 必须用「打包」功能导出 zip（包含所有零件），只传 .SLDASM 算未完成
  • 命名：E4_底板组件_姓名.zip
  • 附无干涉截图

八、常见错误

  1. 第一个零件没固定 → 装配体第一个零件必须固定，否则全散。
  2. 配合过定义 → 删除多余配合；配合文件夹里看红色报错项。
  3. 不打包就交 → 换电脑零件全丢，永远用「打包」。
  4. 零件透明/找不到 → 特征树右键零件 → 「显示」。
