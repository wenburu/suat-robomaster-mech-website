E2 · 旋转特征

一根中心线，转出所有轴类零件

一、学习目标

  • 理解旋转的原理：轮廓绕中心线转 360° = 回转体
  • 会用旋转做阶梯轴（RM 云台/底盘最常见的零件）
  • 能在轴上做螺纹孔和键槽（后续任务基础）

二、讲义：旋转命令三大铁律

旋转命令报错，99% 是这三条
  1. 必须画一条中心线作为旋转轴（草图标签 → 中心线，不是普通直线）
  2. 轮廓必须画在中心线的一侧
  3. 轮廓必须封闭（可以借助中心线本身作为封闭边）

2.1 旋转步骤

  1. 前视基准面 → 草图
  2. 画一条中心线（竖直，作为旋转轴）
  3. 在中心线一侧画出轴的半剖面轮廓（封闭）
  4. 退出草图 → 「特征」→ 「旋转凸台/基体」
  5. 确认旋转轴选的是中心线，角度 360° → 确定
为什么是"半剖面"？轴是回转体，任何过轴线的截面都是一样的。你只要画出"半边"，转一圈就是整根轴。旋转零件全部这么画。

三、讲义：实例——阶梯轴

我们要做：Φ20 × 30mm + Φ15 × 20mm 的阶梯轴，一端 M6 螺纹孔。

  1. 前视基准面 → 草图
  2. 画竖直中心线（长度约 60mm）
  3. 在右侧画半剖面：外轮廓从上到下：
    水平线 Φ20 段（宽 30）→ 竖直阶梯线 → 水平线 Φ15 段（宽 20）→ 回到轴线上 → 沿轴线闭合
  4. 退出草图 → 旋转 360° → 得到阶梯轴
  5. 选中轴端面 → 草图 → 画 Φ5.2 圆（M6 螺纹底孔）→ 拉伸切除 → 深度 15mm
  6. 特征树全部改名，保存

产出：E2_阶梯轴_姓名.SLDPRT，特征树干净、命名规范。

六、常见错误

  1. 没画中心线，用普通直线当轴 → 旋转命令不知道绕哪转。
  2. 轮廓跨在中心线两侧 → 报错"轮廓与中心线交叉"，把轮廓全挪到一侧。
  3. 轮廓没封闭 → 旋转报错，检查缺口。
  4. 旋转角度输错 → 需要完整回转体就 360°；只转 90° 想生成 1/4 圆环时才用其它角度。
