E2 · 旋转特征

E2 旋转特征：一根中心线，转出所有轴类零件

这一部分讲什么

机器人上到处是"转的东西"：舵机轴、云台轴、轮轴、销。它们都是回转体——绕一根轴线转出来的。SolidWorks 里做回转体用「旋转」命令：画出半剖面轮廓，绕中心线转 360°，就是完整零件。这一部分学旋转，并做出一根阶梯轴。

旋转命令三大铁律

旋转报错，99% 是这三条
  1. 必须画一条中心线作为旋转轴（草图标签 → 中心线，不是普通直线）
  2. 轮廓必须画在中心线的一侧
  3. 轮廓必须封闭（可以借助中心线本身作为封闭边）

旋转步骤

  1. 前视基准面 → 草图
  2. 画一条中心线（竖直，作为旋转轴）
  3. 在中心线一侧画出轴的半剖面轮廓（封闭）
  4. 退出草图 → 「特征」→ 「旋转凸台/基体」
  5. 确认旋转轴选的是中心线，角度 360° → 确定
为什么是"半剖面"？轴是回转体，任何过轴线的截面都是一样的。只要画出"半边"，转一圈就是整根轴。所有旋转零件都这么画。

实例：阶梯轴

做一根 Φ20 × 30mm + Φ15 × 20mm 的阶梯轴，一端带 M6 螺纹底孔。

  1. 前视基准面 → 草图
  2. 画竖直中心线（长约 60mm）
  3. 在右侧画半剖面：外轮廓从上到下——水平线 Φ20 段（宽 30）→ 竖直阶梯线 → 水平线 Φ15 段（宽 20）→ 回到轴线上 → 沿轴线闭合
  4. 退出草图 → 旋转 360° → 得到阶梯轴
  5. 选中轴端面 → 草图 → 画 Φ5.2 圆（M6 螺纹底孔）→ 拉伸切除 → 深度 15mm
  6. 特征树全部改名，保存

为什么底孔是 Φ5.2？M6 螺纹的底孔直径标准是 5mm（内螺纹底孔≈公称直径−螺距，M6 螺距 1，即 6−1=5；加工常用 5.0~5.2）。这类"标准孔尺寸"后面 D 阶段会系统学。

练习

常见问题

  1. 没画中心线，用普通直线当轴：旋转命令不知道绕哪转。
  2. 轮廓跨在中心线两侧：报错"轮廓与中心线交叉"，把轮廓全挪到一侧。
  3. 轮廓没封闭：旋转报错，检查缺口。
  4. 旋转角度输错：完整回转体用 360°；只转 90° 是在做 1/4 圆环时才用。
