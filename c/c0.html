C 阶段：工程图与标注

这一部分讲什么

C 阶段解决「把 3D 模型变成可加工、可检验的 2D 工程图」：视图怎么摆、尺寸怎么标、公差怎么给、BOM 怎么写。D 阶段做出来的每个零件，都要出工程图交给加工和审核。

前置条件：D 阶段完成（有真实的零件和装配体可出图）。这一页先给出整体框架与学习路径，任务明细在 D 阶段推进过程中补充细化。

核心内容（框架）

模块内容预计时间
C1视图基础：标准三视图、等轴测、局部放大、剖面视图3-4h
C2尺寸标注：智能尺寸、基准、尺寸规范（按国标习惯）3-4h
C3公差与配合：尺寸公差、形位公差概念、配合选择（E4 配合的图纸化）3-4h
C4装配图与 BOM：装配体工程图、材料明细表、图框标题栏3-4h
C5阶段作业：给 D 阶段自己的零件出完整图纸一套4-6h

讲义正文（要点预览）

1. 为什么需要工程图

3D 模型用于设计，工程图用于加工和检验：加工厂不看模型，只看图纸上的尺寸和公差。工程图必须自洽：图里标了尺寸，就按图加工；没标，加工方按默认习惯处理。

2. 视图

标准三视图（主视/俯视/左视）是基础，加上等轴测帮助理解，内部结构用剖面视图表达。视图之间保持投影关系（长对正、高平齐、宽相等）。

3. 尺寸与公差

尺寸要标加工需要的，不是标模型里的全部尺寸；公差表达允许的偏差范围（如 Φ10 ± 0.05），配合处公差从严。

练习项目（框架）

  1. 用 F4 连接板出第一张三视图工程图，练习视图与标注
  2. 用 E2 阶梯轴做剖面视图，标注尺寸与公差
  3. 用 D 阶段自己的装配体出装配图 + BOM

提交要求（框架）

工程图 .SLDDRW 或 PDF，命名：C_零件名_姓名.SLDDRW；阶段作业整套图纸 + 审核意见。

常见错误（预览）

  • 视图投影关系错位
  • 重复尺寸 / 漏关键尺寸（加工无法做）
  • 公差乱给（能加工但不必要地严）
  • 图框标题栏不填（材料、比例、零件名缺失）
