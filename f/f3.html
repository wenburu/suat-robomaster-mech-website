F3 · 约束与尺寸

F3 约束三态、几何约束、智能尺寸

这一部分讲什么

草图画出来之后是"活的"——线可以乱拖。这一部分讲怎么把草图"钉死"：用几何约束（平行、垂直、相切）和尺寸（智能尺寸）让每条线、每个圆都有确定的位置和大小。钉死之后草图变黑色，叫"完全定义"。

草图三态：蓝、黑、红

颜色状态意思
蓝色欠定义还能拖得动，位置/大小没定死
黑色完全定义动不了了，尺寸和约束都齐了
红色过定义约束给多了，冲突了，要删掉多余的
目标交出去的草图一律黑色（完全定义）。这是 F 阶段最重要的习惯。

几何约束

几何约束表达"线之间的关系"，不用标数字：

约束图标作用
水平—线保持水平
竖直丨线保持竖直
垂直⊥两条线垂直
平行∥两条线平行
相切⌒线和圆相切
重合⊕点落在线上/点上
相等=两条线等长、两个圆等大
对称⇄两点关于中心线对称

添加方法：按住 Ctrl 同时选中两个对象 → 左侧属性管理器会出现约束按钮 → 点一个。

智能尺寸

智能尺寸管"多少"：多长、多大、间距多少。

  1. 点「智能尺寸」（或按 D）
  2. 点一条线 → 拖动 → 输入数值（如 120）
  3. 点两个圆心 → 拖动 → 输入间距
  4. 点一个圆 → 得到直径（改直径直接输数）
单位默认单位是毫米（mm），RM 零件全部用毫米，不用改。

完全定义草图

草图全黑就是完全定义。如果还欠定义，有两个办法：

  • 看蓝色：哪条线还是蓝的，就给它补尺寸或约束
  • 一键解决：「草图」标签 → 「完全定义草图」→ 软件自动补齐

完全定义不是"越多越好"，多了变红（过定义），删掉多余的那个即可。

练习

  1. 练习 1（20 分钟）：画一个矩形，给四条边标尺寸（120×80），再画一条对角线，用"相等"约束让两条对角线相等——观察颜色从蓝变黑。
  2. 练习 2（30 分钟）：画"L 形板"草图：外形 100×60，右下角挖掉 40×30（画两段线补上），全部标尺寸，最终全黑。

没有电脑的同学：方格纸上把 L 形板画出来并标全尺寸（长 100、宽 60、缺口 40×30），拍照保存。

自检

  • 练习 2 的 L 形板草图全部变黑（完全定义），属性管理器显示 Fully Defined
  • 尺寸标注能正确驱动几何：改一个尺寸，图形跟着变
  • 能说出欠定义 / 完全定义 / 过定义三态分别对应什么颜色

常见问题

  1. 尺寸标了还是蓝色：还缺约束。比如矩形四条边都有尺寸但还能整体平移——补一个"固定"约束或标注到原点。
  2. 红色过定义：删掉最后加的那个约束/尺寸，再试。
  3. 尺寸变得很奇怪（比如变成 0.01）：点错了对象或拖动方向反了，Esc 重来。
  4. 约束按钮是灰的：先按住 Ctrl 选中两个对象，按钮才会亮。
