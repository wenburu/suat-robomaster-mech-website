F3 · 草图约束与尺寸标注

让草图"变黑"，不再散架

一、学习目标

  • 理解"完全定义"：草图从蓝色变成黑色
  • 分清欠定义 / 完全定义 / 过定义三种状态
  • 掌握常用几何约束：水平、竖直、重合、对称、相等
  • 会用智能尺寸标注关键尺寸

二、讲义：三种状态（F 阶段最重要概念）

状态线条颜色含义怎么办
欠定义蓝色还能拖动，位置/大小没定死继续加约束和尺寸
完全定义黑色所有自由度都被锁住，拖不动✅ 目标状态，可以安心拉伸
过定义红色报错约束/尺寸给重复了，冲突删掉多余的约束
为什么必须完全定义？草图欠定义就去拉伸，模型参数是"漂"的。改一个尺寸，其它部分可能乱跑，后面装配和出图全乱。RM 零件尺寸必须可控，这是机械工程师的基本功。

三、讲义：几何约束（先加约束，再标尺寸）

约束 = 告诉软件"这两条线必须保持什么关系"。命令入口：草图 → 显示/删除几何关系，或选中两条线后右键选"添加几何关系"。

约束图标作用典型用途
水平 / 竖直— / |把线摆正底板轮廓线
重合⌖两点/线贴在一起圆心落在某条线上
相等=两条线一样长对称零件的一半
对称⇆绕中心线镜像对称左右对称的孔位
相切◎圆弧与直线相切圆角过渡

操作原则（记死）：先加几何约束 → 再标尺寸。约束管"形状关系"，尺寸管"具体数值"。

四、讲义：智能尺寸 S

  1. 点智能尺寸：草图标签 → 智能尺寸，或按 S
  2. 标直线长度：点直线 → 移动鼠标 → 点一下放置尺寸
  3. 标圆直径：点圆 → 移动 → 放置（显示 Φ）
  4. 标两孔距离：先点一个圆心 → 再点另一个圆心 → 放置
  5. 输入数值：弹出对话框，输入 100 → 回车
小技巧尺寸放好后直接双击它，可以快速改数值。尺寸一旦与约束冲突会变红，说明有矛盾，检查哪里加错了。

五、练习项目

项目名称：L 形板（F 阶段必做，F4 考核会用到类似图形）

  1. 前视基准面 → 草图，画一个 L 形：外轮廓 100×80，内凹 40×40
  2. 先加约束：所有外轮廓线标水平/竖直；内凹的角与外形对齐加重合
  3. 再加尺寸：100、80、40、40 四个关键尺寸标完
  4. 验证完全定义：所有线条变黑；试着拖动任意一条线，拖不动 = 成功
  5. 检查状态：右下角状态栏显示"完全定义"

产出：完全定义的 L 形板草图（截图 + .SLDPRT）。

八、常见错误

  1. 以为尺寸标得越多越好 → 错。约束优先，尺寸只标关键尺寸；标多了反而过定义。
  2. "假完全定义" → 变黑后要拖动验证；有时只是"局部定义"，拖一下才发现没锁住。
  3. 过定义报错不会删 → 右键有问题的线 → "显示/删除几何关系"，找到红色冲突项删掉。
  4. 两条线明明该相等，分别标了两个尺寸 → 用"相等"约束，改一处自动同步，这才是参数化设计。
