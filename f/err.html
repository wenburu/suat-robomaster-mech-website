F 阶段 · 常见错误合集

前人踩过的坑，你不用再踩

一、版本与软件

  1. 版本不统一 → 全组锁定 SolidWorks 2026，别装 2024/2025。
  2. 用破解版 → 严禁。文件不兼容 + 法律风险，一律官方教育许可。
  3. 打开卡在"正在准备" → 重启电脑 / 管理员身份运行。

二、草图

  1. 草图欠定义就拉伸 → 先变黑（完全定义）再退出草图。
  2. 尺寸标得越多越好 → 错。约束优先，尺寸只标关键尺寸。
  3. "假完全定义" → 变黑后要拖动验证，拖不动才是真定义。
  4. 过定义不会删 → 右键线条 → "显示/删除几何关系"，删红色冲突项。
  5. 草图没封闭就退出 → 检查出头线，用修剪/延伸闭合。

三、建模习惯

  1. 特征树乱 → 每个特征右键重命名："拉伸-板厚5mm"。
  2. 文件乱存乱命名 → 统一 任务_姓名_日期.SLDPRT，按任务归档。
  3. 打孔用凸台 → 孔是「拉伸切除」，记死。

四、协作

  1. 3D 打印文件自己发群 → .STL 统一交加工负责人，机械组不负责打印执行（学校/运营组负责）。
  2. 无电脑成员掉队 → 结对成员每周确认一次进度，组长组会过一遍。
  3. 作业最后一天才交 → 周日 23:59 截止，逾期按组规处理。
