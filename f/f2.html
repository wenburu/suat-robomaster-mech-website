F2 · 草图绘制基础

六个命令，画出任何草图

一、学习目标

  • 掌握 6 个核心草图命令：直线、矩形、圆、圆弧、修剪、延伸
  • 理解"草图要画在基准面上"
  • 养成看右下角提示栏的习惯

二、讲义：进入草图

  1. 新建零件：文件 → 新建 → 零件
  2. 选基准面：在特征树里点一下"前视基准面"（它会高亮）
  3. 进入草图：顶部「草图」标签 → 点「草图绘制」，或直接按快捷键画

进入后右下角会出现提示栏，显示当前鼠标状态（如"水平""竖直""重合"）。画图永远盯着右下角提示，它是你的导航仪。

三、讲义：六个核心命令

3.1 直线 L

  1. 点「直线」命令，鼠标变成铅笔
  2. 在图形区点第一下（起点），拖动，点第二下（终点）
  3. 想连续画：继续点第三下、第四下……按 Esc 或双击结束
  4. 注意：线旁出现红色小符号 = 自动添加了约束（水平/竖直），这是好事

3.2 矩形 R

常用两种：

  • 边角矩形：点第一个角 → 拖到对角 → 松手
  • 中心矩形：先点中心 → 再拖出一个角（对称零件超好用）

3.3 圆 C

  1. 点「圆」命令 → 先点圆心 → 拖动定半径 → 点一下完成
  2. 画"中心圆"（圆心在某个点/中点/交点上）：先捕捉该点再拖
捕捉提示鼠标靠近中点/端点/交点时会出现绿色小方块/圆点，这就是捕捉，画准的关键。

3.4 圆弧

  • 三点圆弧：起点 → 终点 → 弧上一点（最常见）
  • 圆心/起/终点圆弧：圆心 → 起点 → 终点（画规则圆角用）

3.5 修剪 T（剪掉多余）

  1. 点「修剪实体」→ 鼠标划过要删掉的线段
  2. 线段像被刀割一样消失

3.6 延伸（补上断口）

  1. 点「延伸实体」→ 点要延伸的线段的端点一侧
  2. 它会自动伸到碰上下一条线为止
最容易忽略的一步草图画完想退出，点右上角/命令栏的「退出草图」。不退出就做不了拉伸等特征。

四、练习项目

练习 1（必做）：100mm × 60mm 的矩形，四角倒 R10 圆角。

  1. 前视基准面 → 草图
  2. 按 R 画边角矩形（尺寸先不管，F3 学完标尺寸）
  3. 用「圆角」命令（草图标签页里）：依次点矩形相邻两边，半径先随便，F3 标尺寸
  4. 退出草图，另存为 F2_姓名_日期.SLDPRT

练习 2（选做）：矩形中心画一个 Φ20 圆（捕捉矩形中心点）。

产出：两张草图截图（含右下角提示栏），或一个 .SLDPRT 文件。

七、常见错误

  1. 画线不看右下角提示 → 线是歪的还不知道，必须养成看提示的习惯。
  2. 不退出草图就点拉伸 → 有些版本能直接转，有些会报错；先退草图再做特征，习惯统一。
  3. 矩形画成了四条独立的线 → 用「矩形」命令一次画成，别用四条直线拼。
  4. 修剪把要留的线剪了 → 按 Ctrl+Z 撤回，别硬改。
