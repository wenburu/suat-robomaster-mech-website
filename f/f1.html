F1 · SW2026 安装与界面熟悉

把软件装好，认识它，别慌

一、学习目标

  • 正确安装并激活 SolidWorks 2026（学生版 / RM 教育许可）
  • 说出界面四大区域的位置和用途
  • 会用鼠标三键旋转、平移、缩放视图

二、讲义：安装与激活

2.1 版本铁律

全组统一：SolidWorks 2026只允许学生版或 RM 教育许可，严禁破解版。理由：① 破解版文件与正版互相打不开，全组协作直接崩；② 组内传播破解工具有法律风险；③ RM 官方培训/裁判检查版本时会出问题。

2.2 安装步骤

  1. 拿到安装包：由组长/运营组统一提供 2026 安装包或学生版下载渠道（MySolidWorks 学生账号），不要各自从网上乱下。
  2. 关闭杀毒软件：安装过程可能被拦截，装完可再开。
  3. 以管理员身份运行安装程序：右键安装包 → 以管理员身份运行。
  4. 选择安装位置：默认 C 盘即可；如果 C 盘紧张，改到 D 盘，但记下路径（后面找文件要用）。
  5. 等待 10-30 分钟：中途别关电源别强制退出。
  6. 激活：学生版用学校/官方提供的序列号在教育许可通道激活；RM 教育许可按官方指引操作。激活失败截图发群里求助，已装同学远程指导。
安装失败怎么办① 重启电脑再试一次；② 检查安装包是否完整（大小是否一致）；③ 别自己找"绿色版/破解版"——找组长或已装同学，换官方渠道。

三、讲义：认识界面（对着软件指一遍）

首次打开：文件 → 新建 → 零件，进入建模界面。记住四大区域：

区域位置作用零基础怎么用
特征树（设计树）左侧记录建模历史，从下往上就是你的操作步骤想改哪里，就在树里找到那一步，右键→编辑
属性管理器左侧（点命令时弹出）设置当前命令的参数点了"拉伸"它就出现，参数在这里填
图形区中间画图和看模型的地方鼠标操作都在这里发生
命令管理器顶部功能区：草图/特征/装配体等标签页先点标签页，再点里面的命令按钮

3.1 鼠标三键（最关键，马上练）

操作效果说明
滚轮滚动视图缩放往前放大，往后缩小
按住滚轮拖动视图平移把模型"抓住"移来移去
按住中键/右键拖动视图旋转绕模型转圈看
右键快捷菜单弹出上下文操作
练手动作打开软件后，随便建个零件，用鼠标三键把视图转几圈、放大缩小几次，直到不假思索能完成。

3.2 三个基准面

建模要"躺在"某个面上画草图。SolidWorks 默认三个基准面：前视、上视、右视。F2 起会频繁用到，现在只需知道它们存在于特征树最上面，且可以隐藏/显示（视图 → 隐藏/显示 → 基准面）。

四、练习项目

项目名称：界面熟悉练习

  1. 新建零件：文件 → 新建 → 零件 → 确定
  2. 画一个矩形：顶部「草图」标签 → 选择"前视基准面" → 点「矩形」→ 在图形区拖出一个矩形 → 观察特征树出现了什么
  3. 观察：特征树出现"草图1"了吗？属性管理器弹出过参数吗？
  4. 截图：把整个界面截图，用画图工具圈出四大区域，标注名称

产出：一张标注好的界面截图（四大区域 + 特征树里的"草图1"）。

💡 弹性方案：无电脑 / 未装 SW

无电脑成员（11 月中旬购机）：

  1. 看阿奇教程第 1 集 2 遍，边看边做笔记
  2. 找结对成员要"界面四区标注截图"，自己对照复述每区作用
  3. 在纸上画出界面布局草图（四区位置 + 基准面），拍照提交
  4. 电脑到位后 2 天内补 F1 实操截图

未装 SW / 配置不确定：本周先解决安装；装完跑一个矩形草图测流畅度；卡顿明显 → 用机房电脑补练。

七、常见错误

  1. 装错版本（装了 2024/2025）→ 与全组文件不兼容，重装 2026。
  2. 打开卡在"正在准备" → 重启电脑；或用管理员身份运行 SolidWorks。
  3. 在群里发破解激活工具 → 立即撤回，组内通报；一律走官方许可。
  4. 找不到特征树 → 界面左侧若收起，点左下角"特征"标签展开。
  5. 鼠标操作不熟练 → 别急，练 10 分钟就有感觉，这是肌肉记忆。
