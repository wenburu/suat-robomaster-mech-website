F4 拉伸、切除、圆角：做出第一块零件

这一部分讲什么

二维草图怎么变成三维零件？靠"拉伸"：把草图沿垂直方向拉出厚度，就是凸台；把已有的实体"挖掉"一块，就是切除。这一部分做完，能交出第一块真正的零件——连接板。

拉伸凸台（长出实体）

  1. 画好一个封闭草图（如 F3 的 L 形板）
  2. 「特征」标签 → 「拉伸凸台/基体」
  3. 属性管理器里：方向 1 输入厚度（如 5mm）
  4. 点「完成」
前提草图必须封闭（没有缺口、没有多余的交叉线），拉伸命令才认。

拉伸切除（挖掉材料）

  1. 选零件的一个面 → 进入草图
  2. 画孔的形状（如 Φ10 圆）
  3. 「特征」→ 「拉伸切除」
  4. 输入深度：完全贯穿或指定 5mm → 确认
完全贯穿孔通常选「完全贯穿」，一次挖穿整个零件，不用算深度。

圆角

「特征」→ 「圆角」→ 选一条边 → 输入半径。RM 零件大量用圆角：一是安全（不划手），二是强度（尖角应力集中容易断）。

做第一块零件：连接板

图纸（单位 mm）：

  • 外形 120×80，厚度 5
  • 四角 M3 沉头孔：Φ3.4 过孔，距边 10mm
  • 中心 Φ20 孔
  • 四边 R5 圆角
  1. 前视基准面 → 画 120×80 矩形（完全定义）
  2. 拉伸凸台 5mm
  3. 顶面进入草图 → 四角 Φ3.4 圆 + 中心 Φ20 圆 → 拉伸切除「完全贯穿」
  4. 四条边倒 R5 圆角
  5. 文件另存为 F4_连接板_姓名.SLDPRT，按 Ctrl+7 等轴测截图

练习

练习：把上面的连接板做出来。做顺了之后，试着把外形改成 100×60、孔距改成 8mm，看模型怎么跟着变（这就叫参数化）。

没有电脑的同学：画出连接板的三视图（主视/俯视/左视），标全尺寸，拍照保存。

常见问题

  1. 拉伸是灰的/报错：草图有缺口或交叉线。退回去检查草图，把多余的线删掉。
  2. 孔不见了：可能拉伸方向反了或深度不够，改深度或反向。
  3. 草图画在零件外面：画之前先点中要画的那个面。
  4. 圆角失败：半径大于边线可容纳范围，减小半径。
