F4 · 简单拉伸零件练习

从草图到第一个三维零件

一、学习目标

  • 掌握拉伸凸台：把 2D 草图变 3D 实体
  • 掌握拉伸切除：在实体上打孔（孔是切除，不是凸台！）
  • 会用倒圆角
  • 完成第一块"连接板"零件——RM 里最常见的零件类型

二、讲义：三个核心特征命令

2.1 拉伸凸台（加材料）

  1. 画好完全定义的草图（F3 的技能）
  2. 点右上角「退出草图」
  3. 顶部「特征」标签 → 点「拉伸凸台/基体」
  4. 属性管理器里：输入深度（如 5mm），看预览箭头方向对不对
  5. 点 ✅ 确定

2.2 拉伸切除（去材料 = 打孔）

  1. 先选中实体上要打孔的那个平面（点一下面，它会高亮）
  2. 点「草图绘制」→ 在这个面上画孔的位置和大小（完全定义）
  3. 退出草图 → 「特征」标签 → 「拉伸切除」
  4. 深度选「完全贯穿」→ 确定
打孔永远用「拉伸切除」新手最容易犯的错：想打孔却用"拉伸凸台"，结果长出一根柱子。记住：加材料 = 凸台，去材料 = 切除。

2.3 倒圆角

  1. 「特征」标签 → 「圆角」
  2. 点要倒角的棱边（可多选）
  3. 输入半径（如 2mm）→ 确定

三、讲义：M 螺丝与孔的关系（RM 必备常识）

RM 结构上大量用 M3 / M4 / M5 螺丝。孔的大小有讲究：

螺丝规格通孔直径（过孔）螺纹孔用途举例
M3Φ3.3~3.5M3 螺纹孔碳板、小件连接
M4Φ4.3~4.5M4 螺纹孔常见结构连接
M5Φ5.3~5.5M5 螺纹孔受力较大处

本任务用 M6 举例（通孔 Φ6.6）只是练手；D 阶段设计步兵时，记住查"螺丝过孔表"，别凭感觉开孔。

四、练习项目

项目名称：一块连接板（120 × 80 × 5mm）

  1. 前视基准面 → 草图 → 画 120×80 矩形并完全定义 → 退出草图
  2. 拉伸凸台 → 深度 5mm
  3. 选中上表面 → 新建草图 → 画四个角 Φ6.6 圆（距边 10mm）+ 中心 Φ20 圆，全部完全定义
  4. 退出草图 → 拉伸切除 → 完全贯穿
  5. 四条竖棱边倒 R2 圆角
  6. 按 Ctrl+7 切到等轴测视图，截图

产出：F4_姓名_日期.SLDPRT + 等轴测截图。

完成标准打开特征树检查：应该有「草图1 → 拉伸1 → 草图2 → 切除1 → 圆角1」这样一个干净的历史链。特征树乱 = 没做对。

七、常见错误

  1. 打孔用凸台 → 孔是切除不是凸台，记死。
  2. 拉伸方向反了 → 看绿色预览箭头，反了就点属性管理器里的"反向"。
  3. 在实体上画草图选错面 → 新手统一从前视/上视/右视基准面开始，再练选面。
  4. 深度用默认值不检查 → 拉伸 5mm 一定要在属性管理器确认深度是 5。
  5. 特征树不重命名 → 每个特征右键重命名："拉伸-板厚5"、"切除-M6孔"。
