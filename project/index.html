第一台步兵：仿制东大全向轮车

目标：一月底出一台能跑、能转、能发射的整车。做法是完全仿制东北大学 T-DT RM2023 全向轮步兵，不自创结构，先把一台车复刻出来。阶段学习不停，两条线并行。

一、这件事和学习怎么并行

两条线分开记，不互相顶替：阶段线照常推进，E6 考核保留作保底；项目线按本页九周计划走，交付物是实物。

两条线会在时间上打架：十二月中下旬是考试周，进度必然掉。所以 W4 的总装压到 12/21 之前，后面留缓冲。掉了一周就在本页写明掉了哪一周，不要悄悄顺延。

二、参考图纸怎么用

开源资料在 RoboMaster 社区（RM2023 全向轮步兵开源，网盘地址与提取码见原帖）。按顺序读，不要一上来就拆零件：

  1. 先看总装：整车长宽高、轮距、轴距、离地间隙、云台回转范围，各记一组数。
  2. 再拆模块：底盘、轮系、传动、电池仓、立柱、云台、发射，逐块看。
  3. 列两张清单：能买的（电机、轮组、轴承、螺丝、板材）与要做的（打印件、加工件）。

开源文件与实车未必一致，收到实物后以实测为准；图纸标注缺失处自己补测，不按比例猜。

四、件怎么分

  • 底盘与传动组：底板、车架、轮系、传动、电池仓。
  • 云台与发射组：轴系、发射、弹仓、枪管、立柱。
  • 全组轮值：打印排产、装配、返修，按周轮，不固定给一个人。
  • 没人认领的件：周会现场指派，结果写进「当前状态」。

五、打印与装配的规矩

打印件出问题，八成不是模型错，是参数和摆放方向错。统一按下面来，改参数要在本页记一笔。

  • 参数：起步 0.2 mm 层高、3 层壁、20% 填充；受力件（轮安装座、云台臂、立柱）加到 4 层壁、40%。
  • 孔位余量：留 0.2–0.3 mm，装不进先扩孔，不要硬敲，敲进去的件下次就裂。
  • 螺纹：不在打印件上直接攻丝，用热熔铜螺母，或贯穿螺栓加螺母。
  • 摆放方向：层纹垂直于主受力方向时最弱，摆件让层纹顺着受力方向。
  • 装配顺序：轮系 → 底板 → 传动 → 电池仓 → 立柱 → 云台 → 发射，每装完一级拍一张照。
  • 返修留痕：改过的件留前后对比照，写清改了什么，别只写「已修」。

六、每周怎么同步

本页每周日 21:00 前更新一次，只写三行：这周做完什么、卡在哪、下周谁做什么。写具体件名，不写「推进中」。

组内日志只记里程碑：首件打印完成、底盘落地、云台能转、整车首次跑动。日常进展留在本页，不往日志里堆。

七、三个会被低估的风险

  • 全向轮不是麦轮。四轮固定布局的全向轮没有侧向驱动力，想横移必须配转向机构。先确认参考车的轮组带不带转向，再定轮系方案；按麦轮思路装会得到一台只能前后走的车。
  • 加工周期。外协件一到两周，打印件两到四天。晚一周下单，后面每一环都晚一周。
  • 考试周掉进度。十二月中下旬必然慢下来，W4 的总装不能再往后压。
