A 阶段：整车集成

这一部分讲什么

A 阶段解决「把子系统合成一辆能跑的 1v1 步兵」：整车集成、接口对齐、全流程跑通（设计 → 出图 → 加工 → 装配 → 测试）。这一页给框架，任务明细在 D/C/B 完成后补充。

核心内容（框架）

模块内容预计时间
A1整车总装：底盘 + 云台 + 装甲 + 电控接口合成4-6h
A2接口与走线闭环：全车线束路径、快拆检查3-4h
A3整车干涉与运动验证：全行程无干涉3-4h
A4加工与装配闭环：图纸 → 加工件 → 实物装配视加工周期
A5测试与迭代：场地实测 → 问题清单 → 改版持续

讲义正文（要点预览）

1. 整车集成的顺序

底盘总装 → 云台总装 → 装甲 → 电控/线束。每加一层做一次干涉与重心检查，不攒到最后。

2. 接口是核心

所有跨组接口（云台-底盘、装甲-车架）用同一张接口尺寸表管理，改一处必须通知对方。

3. 全流程的意义

A 阶段的产出不是「一辆车」，是一条能复用的流程：1v1 跑通后，3v3 的其他车型（英雄/哨兵）按同一流程扩展。

练习项目（框架）

  1. 整车总装 + 干涉清零 + 重心标注
  2. 全车线束路径图
  3. 一次完整加工装配闭环（含问题记录表）

提交要求（框架）

整车打包 + 干涉报告 + 问题清单。命名：A_整车总装_v版本.zip。

常见错误（预览）

  • 跨组接口各改各的，到总装对不上
  • 线束无规划，运动部件压线
  • 加工件与图纸不一致（图纸没更新就加工）
