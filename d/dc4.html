DC4：电池仓与内部布局

这一部分讲什么

电池是整车最重的模块，也是能量来源。这一部分做电池仓：怎么固定、怎么快拆、怎么走线，以及内部布局怎么保证重心。

讲义正文

1. 电池选型与位置

电池位置在底盘底部中央（重心最低、最居中）。选型（容量、放电倍率、尺寸）由电控/运营对接，机械组拿到电池实物尺寸后做仓体。

2. 电池仓设计

  • 仓体尺寸 = 电池尺寸 + 每侧 1-2mm 间隙 + 缓冲垫厚度
  • 固定方式：两侧限位 + 顶部压板/绑带，保证剧烈转向时不窜动
  • 快拆：比赛换电要快，压板用快拆螺栓或卡扣，别用需要工具的深埋螺丝
  • 电池输出线出口留孔，线束固定（线夹/扎带孔），防止拉扯端子

3. 走线与重心

  • 整车走线沿车架内侧预留线槽，线与运动部件（轮子、悬挂）保持距离
  • 重心验证：装配后把整车重心投影标在底板上，偏差超过要求就调整电池位置或配重

4. 安全

电池仓必须有防穿刺、防短路的隔离（仓体不接触尖锐结构）；电调/线束远离电池发热区。这些在结构评审时由标准与审核负责人检查。

练习项目

  1. 电池仓建模（主练习）：按一个假想电池（如 150×50×40mm）做仓体：底托 + 两侧限位 + 顶部压板 + 出线孔。
  2. 装进底盘：把电池仓装进 DC2 底板，验证重心位置与快拆操作。
  3. 走线规划：在底盘装配里画出线束走向（用 3D 草图或简化线缆），标出固定点。

提交要求

电池仓 .SLDPRT + 装配位置截图 + 重心说明。命名：D_DC4_电池仓_姓名.SLDPRT。

常见错误

  • 仓体尺寸卡死（电池放不进去或晃）
  • 压板需要工具才能拆，换电太慢
  • 出线口太小压线，或没有固定线束
  • 电池放在一侧，重心偏
