DC6：底盘与传动总装

这一部分讲什么

DC6 是底盘与传动组的阶段作业：把 DC1–DC5 的布局、底板、轮系、电池仓、传动装成底盘总成，做干涉检查、导出 BOM、出关键零件工程图。这一部分验证的是「能不能把一个子系统完整地装配、检查、交付」。

讲义正文

1. 装配流程

  1. 新建装配体，按顺序插入：底板（第一个零件固定）→ 轮系子装配 → 传动减速箱子装配 → 电池仓 → 电控板/走线件
  2. 配合选择：底板与轮座用重合 + 同轴心；传动轴与轮用同轴心 + 距离（轴向定位）；运动件（轮轴、齿轮轴）只保留旋转自由度
  3. 插入顺序影响特征树整洁度：从下往上、从大到小、子装配优先

2. 干涉与运动检查

按 DA1 的方法执行：工具 > 评估 > 干涉检查，干涉清零；再做间隙验证（运动件与固定件最小间隙 ≥1 mm）；最后给轮轴加一个旋转马达，用 Motion 的「随时间查找干涉」检查整周转动是否有碰撞。

3. BOM 与工程图

按 DA2 的方法：装配体插入材料明细表，核对零件数量、材料、标准件型号；给传动箱体（或齿轮轴）出一张零件工程图，给底盘出一张装配工程图（含序号与 BOM）。

4. 打包与自检

  • 所有配合无过定义/欠定义
  • 干涉 0 处，间隙验证通过
  • BOM 数量与模型一致，标准件型号齐全
  • 命名、单位、材料齐全；用「打包」导出，别人打开不缺件

练习项目

  1. 底盘总装（主练习）：完成装配 + 干涉检查 + BOM + 关键件工程图 + 打包。
  2. 导出渲染图：用 PhotoView 或外观给底盘一张等轴测渲染图，检查整体比例是否协调。
  3. 评审自述：准备 3 分钟向组内讲：布局依据、传动比选择、每个零件的用途、干涉处理过程。

提交要求

打包文件（.zip） + 干涉检查截图（0 干涉）+ BOM 截图 + 零件工程图 PDF + 渲染图 + 评审自述要点。命名：D_DC6_底盘总装_姓名.zip，发微信群。

常见错误

  • 干涉没清零就交付（仿真和加工都会出问题）
  • 传动箱与底板接口孔位对不上（DC2 阶段没预留）
  • 打包漏零件，别人打开缺件报错
  • 配合过定义导致特征树红叉
  • BOM 数量与模型不一致，标准件没写型号
