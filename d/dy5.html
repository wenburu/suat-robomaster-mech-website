DY5：云台总装与干涉检查

这一部分讲什么

DY5 是云台组的阶段作业：把 DY1-DY4 装成完整云台总成，做干涉检查、导出 BOM、打包交付。与 DC5 同一套验收标准。

讲义正文

1. 装配流程

  1. Yaw 轴承座固定 → Pitch 组件 → 发射机构 → 弹仓/供弹 → 枪管 → 走线件
  2. 运动轴只保留对应自由度（Yaw 只转 Z、Pitch 只转 Y），其余自由度全部约束
  3. 与底盘上板接口对齐（配合底盘组的云台安装孔）

2. 干涉检查与运动验证

  • 工具 > 评估 > 干涉检查，0 干涉
  • 拖动 Yaw/Pitch 检查运动范围：到限位前无干涉、无卡滞
  • 供弹路径放简化弹丸，检查全链路无卡点

3. BOM 与打包

插入材料明细表，核对数量/名称/材料；用打包导出全部文件。

4. 自检

  • 两轴自由度正确、无过定义
  • 干涉 0、运动范围正常
  • BOM 齐全、命名规范
  • 与底盘接口尺寸已在两组间确认

练习项目

  1. 云台总装（主练习）：装配 + 干涉 + 运动验证 + BOM + 打包。
  2. 渲染与自述：等轴测渲染图 + 3 分钟评审自述（结构逻辑、接口对齐、卡弹处理）。

提交要求

打包文件（.zip） + 干涉截图（0 干涉）+ BOM 截图 + 渲染图 + 评审自述。命名：D_DY5_云台总装_姓名.zip。

常见错误

  • 干涉未清零
  • 运动轴自由度残留（能平移或过定义）
  • 与底盘接口尺寸两版不一致
  • 打包缺件
