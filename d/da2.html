DA2：BOM 与工程图（全组必学）

这一部分讲什么

BOM 与工程图是全组必学内容，不随方向。设计最终要变成两样东西：采购与装配看的 BOM，加工看的工程图。你设计的零件能不能被加工出来，取决于图纸是否标全。

学完这一部分，能做到：

  • 在装配体/工程图里插入材料明细表，整理出可交采购的 BOM
  • 出零件工程图：三视图、剖视、定形与定位尺寸、公差、粗糙度、标题栏
  • 出装配工程图：装配视图、零件序号、BOM 表
  • 按统一图幅、比例、线宽导出 PDF

讲义正文

1. BOM（材料明细表）

  • 列：序号、零件号、名称、数量、材料、规格/备注；标准件在备注写型号（如 M3×8 内六角、6202 轴承）
  • 插入：装配体或工程图 → 插入 > 表格 > 材料明细表；选模板，勾选自动更新
  • 同一零件不同配置（长度、孔位）要拆成不同零件号，不能合并数量
  • 采购清单：标准件、板材、加工件分三块列；标准件写清型号规格，交运营组采购；机械组不直接下单

2. 零件工程图

  • 视图：主视（信息最多的一面）、俯视、左视、等轴测；内部结构用剖视（全剖/半剖/局部剖）；细节用局部放大
  • 尺寸：定形尺寸（长宽高、孔径、圆角）+ 定位尺寸（孔中心距、孔到边距离）；不重复、不遗漏、不封闭（不要形成封闭尺寸链）
  • 公差与配合：重要尺寸标公差（± 或 H7/g6 配合代号）；形位公差按需标同轴度、平行度、垂直度
  • 表面与技术要求：粗糙度符号；技术要求写未注公差等级、去毛刺、倒角、热处理
  • 标题栏：图号、名称、材料、比例、设计/审核、日期、版本

3. 装配工程图

  • 装配视图：主视 + 必要剖视，表达零件相互位置；标关键装配尺寸（中心距、安装高度）
  • 零件序号（balloon）：每个零件一个序号，引线不交叉，按顺时针或逆时针顺序排列；序号必须与 BOM 一致
  • BOM 表放在标题栏上方，序号从下往上对应

4. 图纸规范

  • 图幅：A3（420×297）常用，小件用 A4；遵循 GB/T 14689
  • 比例：优先 1:1；大件 1:2 / 1:5，小件 2:1 / 5:1；标题栏比例必须与视图一致
  • 线宽：粗实线 0.5 mm（可见轮廓），细实线 0.25 mm（尺寸线、剖面线）；字体用宋体/仿宋，字高 3.5/5 mm
  • 导出 PDF 时选 1:1，检查线宽与文字是否清晰；PDF 命名与图号一致

5. 图号与版本

  • 图号规则：RM-D-001（战队-阶段-序号），同一零件图号唯一
  • 版本：v1、v2 写在标题栏；每次修改在图框外或单独变更记录里写清改了什么
  • 交付文件命名：D_DA2_图号_名称_姓名.pdf

练习项目

  1. 零件图（主练习）：给 DC5 减速箱的齿轮轴（或箱体）出一张 A3 零件图：三视图 + 剖视 + 完整尺寸 + 公差 + 粗糙度 + 标题栏。
  2. 装配图：给减速箱出一张装配图：主视 + 剖视 + 零件序号 + BOM 表 + 关键装配尺寸。
  3. BOM 导出：材料明细表导出 Excel，标准件单独一列写型号规格。

提交要求

零件图 PDF + 装配图 PDF + BOM Excel + 源文件（打包）。命名：D_DA2_工程图_姓名.zip，发微信群。

常见错误

  • 尺寸漏标，加工时要猜（孔深、圆角、倒角最常漏）
  • 所有尺寸都标 ±0.1，重要的不标、不重要的乱标
  • 剖视方向或剖面线方向错，内部结构表达不清
  • 零件序号与 BOM 对不上，或引线交叉
  • 标题栏空白，比例与实际视图不符
  • BOM 数量与模型不一致，标准件没写型号
